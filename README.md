# Best Food

Site de apresentação de um restaurante, desenvolvido com HTML, CSS e Bootstrap. O projeto reúne informações sobre o estabelecimento, opções do cardápio, eventos e formas de contato em uma única página.

## Sobre o projeto

O Best Food é uma página web criada para apresentar um restaurante de forma organizada e visual. A interface permite navegar entre diferentes seções, conhecer as categorias do cardápio e visualizar imagens dos pratos e do ambiente.

O projeto também foi uma oportunidade para praticar a construção de layouts com Bootstrap e trabalhar com componentes responsivos.

## Funcionalidades

- Navegação entre as seções da página.
- Menu adaptável para dispositivos menores.
- Carrossel de imagens na apresentação do restaurante.
- Seção de eventos com opções para aniversários, casamentos e confraternizações.
- Cardápio separado por categorias:
  - Bebidas não alcoólicas
  - Bebidas alcoólicas
  - Entradas
  - Pratos principais
  - Sobremesas
- Formulário visual para contato.
- Links para redes sociais.

## Como executar

Não é necessário instalar dependências para visualizar o projeto.

1. Clone o repositório:

```bash
git clone https://github.com/Juan-J0rge/Restaurante.git
```

2. Entre na pasta:

```bash
cd Restaurante
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do VS Code para executar a página durante o desenvolvimento.
